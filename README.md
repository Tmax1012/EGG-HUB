# EGG-HUB ELITE v4.0

Interface mobile pour Steal An Egg.

## Fonctions incluses
- Dashboard de session.
- Radar des serveurs publics Roblox (joueurs, capacité, ping et tentative de rejoindre).
- Spawn Predictor manuel basé sur un échantillon communautaire documenté.
- Fusion Calculator manuel.
- Value Notebook de session.
- Egg Database : 13 groupes et 106 emplacements visibles dans un index communautaire.
- Feature Status qui distingue les fonctions disponibles de celles qui ne sont pas prises en charge.
- Fenêtre tactile déplaçable.

## Limites
Le script n'automatise pas le vol d'objets d'autres joueurs, ne lit pas les inventaires cachés, n'exploite pas de remotes non documentés et ne contourne pas l'anti-cheat. Les fonctions Auto Steal, Auto Farm, Auto Sell, Auto Fuse, ESP global et Auto Hatch ne sont pas incluses.

Le Spawn Predictor est basé sur une seule série communautaire en contexte Admin Abuse / update. Il ne s'agit pas d'une garantie universelle.

## Installation
Remplacer le fichier `main.lua` à la racine du dépôt GitHub `Tmax1012/EGG-HUB` par celui du pack. Garder `loader.lua`.

Loader à une ligne :
`loadstring(game:HttpGet("https://raw.githubusercontent.com/Tmax1012/EGG-HUB/main/main.lua"))()`

Les exécuteurs tiers peuvent exposer le compte et entraîner des sanctions Roblox.
